Overview

Farlionary is a lightweight word search application primarily focused on English vocabulary.

https://ikyubie.github.io/Farlionary/

It provides a convenient way to search through a large collection of words gathered from various sources. Whether you are looking for a particular word or need a collection of words for another project, Farlionary aims to make the process simple.

Beyond the web application, Farlionary also provides downloadable plain-text word lists that can be reused for different purposes.

Features

- Extensive Word Collection — Search through a large collection of English words.
- Indonesian Word Collection — Includes a separate collection of Indonesian words.
- Fast Word Lookup — Find matching words through a simple search interface.
- Case-Insensitive Search — Search without worrying about capitalization.
- Downloadable Word Lists — Access word collections in plain-text format.
- Lightweight — Runs directly in your browser as a standalone HTML file.

Word List

The downloadable TXT collection is one of Farlionary's main components.

It can be used as a starting point for projects that require word data, such as:

- Game word databases.
- Word search and word puzzle games.
- Vocabulary-based applications.
- Text processing projects.
- Other word-related experiments.

The word collections are compiled from various sources. Please refer to the original sources and their respective licenses before redistributing or using the data in other projects.

Getting Started

Web Application

1. Download the HTML file from this repository.
2. Open it in your preferred web browser.
3. Select the language you want to search.
4. Type a word into the search field.
5. Explore the matching entries.

TXT Word List

1. Download the available TXT file.
2. Open it using any text editor.
3. Import or process the word entries in your project.

Data Sources

Farlionary's word collections are gathered from various sources, including dictionaries and publicly available word lists.

The collections may be updated or expanded over time.
