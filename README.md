Farlionary.

Farlionary is a word search tool primarily designed for finding English words. It provides access to a large collection of words gathered from various sources, making it useful for word searches and other word-related projects.

In addition to the web-based version, Farlionary also provides a downloadable TXT word list that can be used for other purposes, such as game databases, word-based applications, and personal projects.

Features

- English Word Search — Quickly search through a large collection of English words.
- Extensive Word Collection — Contains a substantial number of words gathered from various sources.
- Indonesian Word Search — Also includes a built-in collection of Indonesian words.
- Case-Insensitive Search — Find words regardless of capitalization.
- TXT Word List — Downloadable plain-text word collection for use in other projects.
- Simple Web Interface — Runs directly in a browser without requiring installation.

Word List

The Farlionary word collection can be useful for various purposes, including:

- Game word databases.
- Word-based games and applications.
- Text processing and word analysis.
- Personal projects that require a word list.
- Other applications involving word lookup or word matching.

The TXT version is provided to make the word collection easier to reuse outside the web application.

Getting Started

Web Version

1. Download the Farlionary HTML file from this repository.
2. Open it in your web browser.
3. Select the desired language.
4. Enter a word in the search field.
5. Browse the matching results.

TXT Version

1. Download the available TXT word list.
2. Open it with a text editor or import it into your project.
3. Process the entries according to your application's requirements.
